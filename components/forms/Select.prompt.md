<Select placeholder="All modules" options={[{ value: 'cr', label: 'ConvertRite' }, { value: 'br', label: 'BidRite' }]} />

Native on purpose — enterprise users keyboard through these. For a searchable list, build a popover on top of `Input` rather than restyling this.
