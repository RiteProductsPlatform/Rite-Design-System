Rite's metric device: a big bold figure over a small lowercase label — exactly how the deck states `20 / Years of Rite`.

```jsx
<StatTile value="150" label="Successful deployments" />
<StatTile value="98.4%" label="SLA adherence" delta="+1.2 pts" icon="gauge" />
```

Deltas are set in IBM Plex Mono. Use `tone="dark"` inside a Deep Forest band — the figure goes white and the icon mint.
