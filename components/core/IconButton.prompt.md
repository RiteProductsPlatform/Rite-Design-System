A square icon-only button for toolbars, table row actions and panel headers.

```jsx
<IconButton icon="settings" label="Settings" />
<IconButton icon="filter" label="Filter" active />
<IconButton icon="download" label="Export" variant="outline" />
```

`label` is required — it is the aria-label and the tooltip. Default variant is `ghost`; use `outline` when the button sits alone on a white card and needs an edge.
